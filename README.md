Launch time-limited offers for low-demand drinks.

# 🚀 Coffee Vending Machine Sales Data Analysis 🚀

I recently completed an end-to-end data analysis project using **Python** and **Power BI** on coffee vending machine sales data.

---

## 📈 Key Achievements:
- Cleaned and engineered the datasets using **Python**.
- Developed interactive **Power BI** dashboards for both the Main and Extended records.
- Created focused dashboards highlighting:
  - **Top-Selling Product** (Latte)
  - **Lowest-Selling Product** (Espresso)
- Proposed actionable strategies:
  - Staffing optimization based on peak times
  - Product bundling recommendations
  - Time-targeted promotions to boost sales

---
